# Storylines — Plus1 launch film

PICKED: A′ — "Saturday, thread-centered" (adapted from A per the person's
steer: agent-to-agent conversation is the centerpiece, story stays genuine).

## A — "Saturday" (recommended: the only one a stranger feels in 2 seconds)

- Device: a moment in someone's day. Form: one continuous take.
- 11pm, Maya gets "hackathon is Saturday, we still need a Python person" —
  the camera pushes from her phone into Plus1, where her agent is already
  searching, and never cuts until the intro lands. The viewer feels rescued.
- First 2s: phone lock screen 11:04pm, message banner drops, camera pushes
  through the banner into Plus1 search.
- Beats: late-night text → cold DM typed and deleted → "Your agent does the
  reaching" → search, thread, report → View thread, intro confirmed →
  "Less searching. More introductions" → end card.
- Look: phone-black opening, then Plus1 paper-white with blue/lime/pink
  status colors; condensed grotesk titles.
- Sound: night-quiet synth pulse turning into a driving 120 BPM beat when
  the agent starts working.

## A′ — PICKED (A refocused: the thread is the film's center)

Same spine as A, but the proof (~40% of runtime) is one full agent-to-agent
conversation played in the real thread UI: Maya's agent opens, Alex's agent
answers, turn counter advances, both owners watching; search compresses to
the thread's on-ramp and the inbox report + approval is the payoff.

## B — "Two inboxes"

- Device: life before and after. Form: split screen to one.
- Left pane churns (tab-hoarding, ignored cold DMs); right pane stays calm
  (agent thread, inbox report); left collapses, calm takes the frame.
- First 2s: split frame — frantic alt-tabbing left, one lime bubble right.
- Beats: split chaos/calm → seen, no reply → "Your agent does the reaching"
  → search, thread, report right → collapse into inbox → claim → end card.
- Look: desaturated grey left world vs full Plus1 color right, same type.
- Sound: glitchy clutter left, clean beat right, one groove after collapse.

## C — "Follow the skill"

- Device: one object across worlds. Form: endless zoom.
- The skill file is the vehicle: dive into "Never oversell me" → network
  search → dive into a result → agent thread → dive into report → inbox.
- First 2s: skill file fills frame, cursor highlights line 3, camera dives
  through the highlight into the network.
- Beats: skill file → dive → "Your agent does the reaching" → search,
  thread, report as dive-stops → inbox holds → claim → end card.
- Look: paper-white throughout, mono skill text, lime highlight as portal.
- Sound: one rising motif restarting higher at each dive, resolving at inbox.
